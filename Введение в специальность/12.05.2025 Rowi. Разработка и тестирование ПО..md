SDLC(Software Development Life Cycle) - это методология, используемая для организации процесса разработки программного обеспечения.
Развёртывание(приложения) - это размещение готовой версии ПО на платформе, доступной для пользователей.
Scrum - это гибкая методология Agile. Полностью самоорганизующаяся команда. Итеративная разработка. Наличие бэклога продукта. Вовлечение 3х ролей. Участие во всех Scrum-ритуалах. 
бэклог - это список задач, идей, требований и изменений в проекте. 
Agile - это философия управления проектами и набор принципов и ценностей, помогающих командам разработчиков программного обеспечения реагировать на изменения. Люди и взаимодействие важнее процессов и инструментов. Работающий продукт важнее исчерпывающей документации.
Waterfall - это каскадёрская модель управления проектами, при которой происходит последовательный переход с одного этапа на другой, при этом пропуск отдельного этапа и возврат на предыдущие стадии не предусмотрен. 
Kanban - это система управления проектами, основанная на принципе разделения объёма работы на конкретные задачи. 
MongoDB - это документ-ориентированная система управления базами данных, которая предназначена для хранения больших объёмов данных в формате документов. 
Elastic Search - это открытая распределённая система управления данными и поиска по ним, основанная на поисковом движке Apache Lucene.
Vue.js - JavaScript-фреймворк с открытым исходным кодом для создания пользовательских интерфейсов.
SVELTE - это современный фреймворк для разработки веб-приложений.
PostSQL - это свободная объектно-реляционная система управления базами данных с открытым исходным кодом.
docker - это платформа контейнеризации с открытым исходным кодом, которая позволяет автоматизировать создание приложений, их доставку и управление.
redis - это резидентная система управления базами данных класса NoSQL, работающая со структурами данных типа "ключ-значение".
kafka - это распределённая система обмена сообщениями между серверными приложениями в режиме реального времени.
IEEE Guide to Software Engineering Body of Knowledge(SWEBOK) - это руководство к своду знаний по программной инженерии, опубликованное сообществом IEEE Computer Society
Test Management - активности по планированию работ
Test Design - проектирование тестов
Test Execution - выполнение тестирования 
Test Analysis - анализ полученных результатов
QA Manual - участвует в процессе обеспечения качества разрабатываемого продукта путём совершения предполагаемых действий пользователя вручную.
QA Automation - это подход к тестирования, основанный на использовании автоматизации для выполнения тестовых сценариев и проверки качества программного обеспечения.
QA Performance Engineer - анализирует существующую архитектуру на предмет производительности, а также проводит испытание нефункциональных требований(стабильность, производительность, масштабируемость стрессо и отказоустойчивость)
Software Development Engineer in Test - это специалист, который совмещает в себе навыки разработчика, тестировщика и DevOps. Он принимает участие во всём цикле выпуска программного обеспечения.
Postman - это универсальная платформа для работы с API, которая сочетает в себе мощные инструменты для разработки, тестирования и документирования интерфейсов.
Playwright - это фреймворк от Microsoft для автоматизации тестирования веб-приложений.
REST API - это архитектурный стиль взаимодействия между клиентом и сервером через HTTP.
Оркестратор - это инструмент, который управляет работой множества сервисов или контейнеров в распределённой системе. 
Swagger - это инструмент для документирования и визуализации RESTful APIs.
Валидация - проверка написанного программного кода на качество.
Automated GUI Tests - процесс автоматического тестирования графического интерфейса приложения с помощью специальных программных инструментов. 
Automated API Tests - это процесс автоматического тестирования и проверки функциональности программного интерфейса приложения.
Automated Integration Tests - это тип тестирования ПО, который проверяет интеграцию различных компонентов или систем для обеспечения их правильной работы вместе. 
Automated Component Tests - это автоматизированное тестирование компонентов, которое повышает эффективность и точность процесса за счёт автоматизации ручных тестов.
Automated Unit Tests - это практика использования автоматизированных инструментов и скриптов для выполнения набора предопределённых тестов для отдельных блоков кода. 
Session Based Testing - это метод тестирования ПО.
pytest - это фреймворк для тестирования кода на Python.
Selenium - это комплекс решений для автоматизации работы браузеров и тестирования веб-приложений.
Kotest - это гибкий и мультиплатформенный фреймворк для тестирования на Kotlin.
